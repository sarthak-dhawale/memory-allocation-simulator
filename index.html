Small decisions. Different outcomes.

The memory model behind your simulation.

01

Choose a strategy

First Fit stops at the first free block that fits. Best Fit chooses the smallest suitable block. Worst Fit chooses the largest. Next Fit resumes from its saved search position and wraps around.

02

Know your partitions

Variable partitions split blocks to match a request. Fixed partitions reserve an entire region, leaving unused space inside it.

03

Understand fragmentation

External fragmentation = free memory − largest free block. Internal fragmentation = reserved memory − requested memory in allocated processes.

04

Make memory contiguous

Compaction moves allocated processes together and combines free space. It preserves total free memory and is available in variable mode.

05

Take it step by step

Enable step mode in the studio to inspect each free block. Previous reviews the explanation; completing an allocation commits it only once.

06

Replay a fair workload

Comparisons use independent memory states and identical actions. Recommendations prioritize allocation success, then useful utilization, fragmentation, and search work.
